# Mini Shopping System

A simple Mini Shopping System built with Dart.  
It simulates an online shopping process where users can browse products, add them to a cart, remove items, and choose a payment method.

---

## Features
- Display a list of products with prices.
- Add multiple products with specific quantities to the cart.
- Show the cart with subtotal calculation.
- Remove a product (all items or one unit only).
- Print a final receipt with the total price.
- Choose a payment method:
  -  Visa (with card details + CVV validation).
  -  Cash (prepare the required amount).
